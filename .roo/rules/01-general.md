# Правила проекта LLMNetHelper

## Автономность репозитория

- Репозиторий не зависит от других репозиториев и внешних решений.
  Единственное решение проекта — `src/LLMNetHelper/LLMNetHelper.slnx`.
- Пути в конфигурации (`.env`) — относительные от корня репозитория;
  раннер `run_LLMNetHelper.ps1` нормализует их до абсолютных перед запуском
  процесса агента. Абсолютные пути с дисками в `.env` не использовать.
- Исторические документы происхождения проекта (из репозитория Artas2026) —
  в `plans/`, помечены как архивные; как актуальную конфигурацию не читать.

## Timezone: вся логика — по UTC

- **Все вычисления ведутся по UTC.** Границы окна, дни отчётов, метки времени
  в SQLite — только UTC (`DateTime.UtcNow`, `DateOnly.FromDateTime(...Utc)`).
- Причина: границы дня должны совпадать с UTC-датой хранения отчётов.
- Запрещено использовать локальный часовой пояс в расчётах границ,
  баз и счётчиков.

## Логи: каталог логов агента — `<AGENT__REPORTSDIR>\logs`

- Вывод агента (раннер пишет в `reports\monitoring\logs\monitor-agent.*.log`;
  для демона — `monitor-agent.stdout.log` / `monitor-agent.stderr.log` +
  `monitor-agent.pid`). Ротация вывода демона — 7 дней.
- Общего каталога логов (Writer/Stat/Promtail) в этом репозитории **нет**:
  переменная `LOGS_DIR` удалена из конфигурации — проект автономен.
- Кодировка файлов логов — UTF-8. При чтении через терминал использовать
  `-Encoding UTF8`; предпочтительно читать через инструмент чтения файлов.

## Запуск .ps1: только через явный вызов `pwsh`, никогда `.\script.ps1`

Терминал агентов стартует в **cmd.exe**, а ассоциация расширения `.ps1`
в Windows указывает на `notepad.exe`. Поэтому `.\script.ps1` не исполняется,
а открывается в Блокноте. Любой `.ps1` запускать только так:

```
pwsh -NoProfile -Command "[Console]::OutputEncoding=[Text.Encoding]::UTF8; $OutputEncoding=[Text.Encoding]::UTF8; chcp 65001 > $null; & '<путь_к_скрипту>' <параметры>"
```

- `&`/`-File` — обязательно (минует ассоциацию notepad).
- UTF-8-префикс обязателен (иначе кириллица в выводе ломается).
- Для неинтерактивных запусков всегда `-NoPause` (иначе терминал зависнет).
- Путь — относительно корня `d:/work/LLMNetHelper`.

Подробности — `.roo/rules-code/02-powershell.md`.

## Тесты: только через `dotnet test src/LLMNetHelper/LLMNetHelper.slnx`

См. `.roo/rules-code/01-test.md`.

## Процессы: НЕ завершать без явного разрешения пользователя

- **Запрещено** останавливать/убивать любые процессы (MonitorAgent-демон,
  docker-контейнеры, Loki/Prometheus и т.п.) без **явного** разрешения
  пользователя в текущей сессии.
- Исключение: `run_LLMNetHelper.ps1 -Stop` — останавливает ТОЛЬКО процесс,
  запущенный самим скриптом (PID из файла); сам флаг и есть разрешение.
- Диагностика выполняется **только в режиме чтения**: логи, `netstat`,
  `Get-Process`, HTTP-GET, `docker ps/logs` (без `down/stop`).
- Если для проверки требуется перезапуск — сначала **спросить разрешение**.
